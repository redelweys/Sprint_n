# Sprint 16 — Яндекс.Маршруты

Тесты проверяют точки маршрута на карте, блок выбора маршрута и подготовку к поездке. Покрыты переключение режимов, отображение времени и стоимости, выбор шести видов транспорта в режиме «Свой», открытие формы такси и формы бронирования Драйва.

Ожидаемое поведение в проверках берётся из ТЗ. Тесты, выявляющие воспроизведённый дефект, помечаются `@pytest.mark.xfail` с описанием причины.

Для запуска установи Google Chrome и выполни команды в PowerShell из корня проекта.

```powershell
py -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m pytest test -v -rxX --alluredir=allure-results --clean-alluredir
```

Добавь `--headless` к запуску pytest, если нужно запустить Chrome без окна. Для подготовки отчёта после прогона используй Allure CLI.

```powershell
allure generate allure-results --clean -o allure-report
```

Прямые обращения к WebDriver и явные ожидания находятся в `BasePage`. Фикстуры открывают и закрывают браузер, локаторы и тестовые данные хранятся отдельно. Действия с интерфейсом выполняются через Page Object, а итоговые проверки находятся в `assert`.
